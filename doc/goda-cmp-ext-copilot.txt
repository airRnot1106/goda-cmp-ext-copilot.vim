INTRODUCTION                              *goda-cmp-ext-copilot-introduction*

                                                       *goda-cmp-ext-copilot*
A goda-cmp.vim source that asks copilot.lua for completions.  The source is
named "copilot".  A suggestion of several lines is shown on one line, and
accepting it inserts the lines.

==============================================================================
INSTALL                                        *goda-cmp-ext-copilot-install*

It needs goda-cmp.vim, goda.vim, copilot.lua and Neovim.

https://github.com/Shougo/goda-cmp.vim
https://github.com/Shougo/goda.vim
https://github.com/zbirenbaum/copilot.lua

Add the Go package to your configuration module.  Its Lua module is embedded
in the binary, so no plugin other than copilot.lua needs to be installed: >

	go get github.com/airRnot1106/goda-cmp-ext-copilot.vim
<
==============================================================================
EXAMPLES                                      *goda-cmp-ext-copilot-examples*
>go
	import "github.com/airRnot1106/goda-cmp-ext-copilot.vim/ext/source/copilot"

	b.AddSource(copilot.New(copilot.Params{Copilot: "lua"}))
<
Add "copilot" to `Sources` and call |goda_cmp#build()|.  A suggestion does
not start with the typed text, so give the source no matchers: >go

	"copilot": {
		Mark:                  "[Copilot]",
		Matchers:              []string{},
		MinAutoCompleteLength: new(0),
		IsVolatile:            new(true),
		Timeout:               new(5000),
	},
<
==============================================================================
PARAMS                                          *goda-cmp-ext-copilot-params*

The parameters are also accepted in sourceParams with these JSON names.

copilot		"lua" asks copilot.lua.  Any other value gathers no
		completions.
